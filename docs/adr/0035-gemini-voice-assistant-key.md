# 0035. Gemini голосом: клавиша помощника и ловец Google Карт

- Статус: принято, дополняет 0034
- Дата: 2026-11-07
- Источники: стенд 07.11 (Xiaomi Егора, Android 16, Яндекс удалён, Gemini помощник по умолчанию),
  `LauncherActions.voiceOnly`, `PhoneAssistant.watchPhone`, `RouteIntent.googleMapsDir`

## Контекст

Егор удалил Яндекс и поставил Gemini помощником по умолчанию: «то же самое реализуем для Gemini».

## Решение

Нет Яндекса, есть Google app - кнопка голоса шлёт KEYCODE_VOICE_ASSIST через шлюз ввода активации (у shell на Xiaomi
INJECT_EVENTS нет). Gemini открывается штатной сессией помощника, на заблокированном телефоне отвечает голосом.
Голос Gemini - USAGE_ASSISTANT, его добавили в AudioMix-захват: по USB он в ГУ. Плашка та же, в цветах Gemini.

Маршрут: на «Начни навигацию до X» Gemini открывает Google Карты ссылкой `google.com/maps/dir/...!1d<долгота>!2d<широта>`.
Ловец берёт точку и отдаёт навигатору плитки (Яндекс Навигатор). Перед вопросом закрываем Карты на телефоне, иначе
ссылка уходит в живую задачу и ловец её не видит.

Музыка: Gemini играет только YouTube Music. Её задачу от Gemini закрываем и включаем выбранный плеер Headswap
(не выбран - Яндекс Музыку). Запрос (трек) не переносим.

## Альтернативы

- Gemini на скрытом дисплее (как Алиса), VOICE_SEARCH_HANDS_FREE + перенос плашки: при погашенном экране Google
  закрывает сессию («Main display is OFF»), наш дисплей вторым экраном не считает.
- VOICE_SEARCH_HANDS_FREE на экране телефона: «Interaction blocked because it was requested in the start request».
- `cmd voiceinteraction show`: у shell нет ACCESS_VOICE_INTERACTION_SERVICE.

## Последствия

Карты и музыку Gemini открывает только на разблокированном телефоне («сначала разблокируйте»); выход - Smart Lock
с Bluetooth машины. «Построй маршрут» даёт карточку без Карт, работает «Начни навигацию». Яндекс Музыка по перехвату
на стенде не заиграла (отказ Media3LibraryService), добавлен перебор сервисов - не проверено. Тап по плашке Gemini
на телефоне не закрывает. В машине не проверено.
