# 0020. В режиме рабочего стола звук идёт по Bluetooth, музыку по USB не передаём

- Статус: заменено [0025](0025-desktop-audio-usb-toggle.md)
- Дата: 2026-11-04
- Источники: поездка на Vezel 04.11 (лог `headswap-20261104-111645.log`, «звук по USB выключен в UI»),
  `dex/DexPrefs.kt` (`desktop_usb_playback_audio`), `dex/DesktopAudioLoopback.kt`

## Контекст

В режиме рабочего стола звук приложений можно было отдавать в ГУ по USB: захват микса (media/game/unknown,
с 04.11 ещё голос навигатора) и передача каналом музыки CarLife. Егор проверил на Vezel с выбранным каналом
Bluetooth: музыка играет нормально, подсказки навигатора тоже идут по Bluetooth, всё звучит как надо.

## Решение

В режиме рабочего стола отказываемся от музыки по USB. Весь звук телефона, и музыка, и голос навигатора, идёт
по Bluetooth (A2DP) как у обычного телефона в машине. ГУ на запрос MODULE_CONTROL MUSIC отвечаем MUSIC=0.

## Альтернативы

- Музыка по USB через захват микса — работала, но по Bluetooth на машине лучше и проще. Голос навигатора пришлось бы
  отдельно подмешивать в захват (коммит «Desktop: navigator voice into the media mix»). Для Bluetooth ничего не нужно.

## Последствия

- Код не удаляем, а выключаем: `DexPrefs.usbPlaybackAudio` всегда false, строка «Звук через Headswap» в настройках
  в режиме рабочего стола затемнена с подписью про Bluetooth. Захват микса (`DesktopAudioLoopback`) и сохранённый выбор
  остаются, чтобы вернуть звук по USB одной правкой.
- Без Bluetooth-соединения с ГУ звука в режиме рабочего стола не будет: в интерфейсе нужна подсказка подключить телефон по Bluetooth.
- Режим Android Auto не меняется: там звук по USB остаётся.
