# 0030. Что листают «Слои», выбирают в настройках «Экран»: встроенные виды и любые приложения

- Статус: принято
- Дата: 2026-11-06
- Источники: разговор с Егором 06.11, макет на холсте «Headswap Desktop — лаунчер 4.0» (SettingsHomeLayout,
  SettingsHomeLayers), `launcher/HomeTilesLogic.kt` (`Layer`, `LayerList`, `HomeTilesLogic`), `launcher/LayersUi.kt`

## Контекст

«Слои» на рейке листали жёстко: навигатор, YouTube, музыка (только в двух плашках), часы. Егор хотел, чтобы кнопка
листала выбранные им приложения.

## Решение

- Блок «Слои» (значок и подпись) в разделе «Экран», под «Раскладкой». До него листают прокруткой. «Раскладка» ужата до
  0,87 высоты, чтобы снизу выглядывала шапка «Слоёв» и было видно, что ниже есть ещё.
- Выбор как на нижней панели главного: иконки строкой и «+», до 4 штук. Убирает только крестик в углу иконки, тап по
  самой иконке ничего не делает. Последний слой не убирается.
- «+» открывает выбор приложения (тот же экран, что у «+» нижней панели). Сначала убранные встроенные виды —
  навигатор, музыка, часы, — потом установленные приложения, кроме уже выбранных и навигатора.
- Слой-приложение встаёт в плашку-приложение (бывшая плашка YouTube) — тем же встроенным окном, с «Развернуть».
  YouTube теперь обычный слой-приложение. Слой хранится по пакету, ключ запуска берётся из каталога.
- По умолчанию слои — навигатор, YouTube, музыка, часы: без настройки всё листается как раньше.

## Альтернативы

- Сжать «Раскладку» до трёх рядов и поставить «Слои» под ней без прокрутки, с номерами порядка и подписью
  «по кругу» — Егор отказался: раскладка должна остаться как была.
- Выбор только из четырёх встроенных видов — Егор отказался: по «+» нужно любое приложение с телефона.

## Последствия

- Окно приложения одно (слот `EmbedHost.app`): на экране одна плашка-приложение. Пока приложение в малой плашке,
  «Слои» пропускают слои-приложения. Листание между двумя приложениями запускает уходящее заново.
- Навигатор слоем-приложением не бывает: его пакет живёт в своём окне.
- В «Экране» впервые прокрутка. Если касание ГУ (DOWN/UP с задержкой) не потянет список, понадобится кнопка вниз.
