# 0036. Свои цвета рабочего стола: слайдеры вместо пресетов

- Статус: принято
- Дата: 2026-11-08
- Источники: `launcher/LauncherColors`, `launcher/LauncherSettings` (`SettingsPage.COLORS`), макет «Цветовые схемы
  десктопа» в Claude Design

## Контекст

Стол был только в золоте: тёмном или светлом. Юзеры хотят цвета под свою машину. Егор: «дать пользователю выбор
палитры, чтоб он мог там слайдерами менять цвет».

## Решение

«Вид › Цвета»: три слайдера — оттенок акцента, оттенок фона, насыщенность фона (0 — серый). Ночной и дневной наборы
отдельно, «Тема» выбирает, какой показывать. Яркость не настраивается, её задаёт формула, поэтому текст читается при
любых значениях. Набор по умолчанию отдаёт нынешние ручные палитры `Palettes.DARK/LIGHT` без пересчёта.

Пока открыта страница «Цвета», весь стол показывает редактируемый набор, даже дневной ночью: отдельное окно
предпросмотра не нужно.

Днём акцент тонирует карточки и кнопки. Без этого на светлом фоне менялась только кнопка навигации (Егор: «херня»).

## Альтернативы

- Шесть готовых схем-плиток: Егор отказался в пользу слайдеров. Пресеты по фото штатных тем ГУ юзеров можно добавить
  поверх слайдеров позже.

## Последствия

Слайдеры двигаются только касанием, шайбой ГУ нет. Обложка музыки и её значок в «Слоях» остались золотисто-коричневыми.
