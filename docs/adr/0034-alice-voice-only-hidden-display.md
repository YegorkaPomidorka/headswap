# 0034. Алиса только голосом: скрытый дисплей и плашка

- Статус: принято, дополняет 0026
- Дата: 2026-11-07
- Источники: стенд 07.11 (заблокированный Xiaomi Егора), `launcher/LauncherActions.voiceOnly`, `launcher/AliceVoice`,
  `launcher/AliceVoiceUi`, макет «Алиса на рабочем столе» в Claude Design

## Контекст

Панель Алисы из 0026 на заблокированном телефоне молчит. Сессия помощника Яндекса сразу открывает полное приложение
с `Alice.LOCK_BEHAVIOUR=LOCKED`, а экран блокировки его не пускает. Настройка Яндекса для блокировки у Егора скрыта.
Егор: «Пусть Алиса работает на телефоне. Мне главное, чтоб она прокидывала маршрут внутрь».

## Решение

Настройка «Алиса только голосом» (по умолчанию вкл). Кнопка голоса открывает тот же дочерний дисплей Алисы, но слой
1×1 px в углу: дисплей ALWAYS_UNLOCKED, на ГУ его не видно. За экраном TextureView не отдаёт текстуру, и дисплей не
создаётся. Голос Алисы идёт в ГУ захватом звука рабочего стола (USAGE_MEDIA, CONTENT_TYPE_SPEECH).

Сессия Яндекса открывает MainActivity на экране телефона. Ловец переносит её на скрытый дисплей. Повторное нажатие
закрывает задачи панели и запускает Алису заново: ASSIST поверх живой задачи утаскивал её на заблокированный экран,
прослушивание сбрасывалось. Контекст диалога переживает перезапуск.

Маршрут голосом: «Построй маршрут до X», затем «Поехали на машине». Алиса шлёт `yandexnavi://build_route_on_map`,
маршрут уходит в машинную часть навигатора плитки, «Поехали» жмёт водитель (Егор: сами не жмём). Пустой Навигатор,
открытый Алисой без маршрута, закрываем, иначе маршрут уйдёт в его задачу и ловец его не увидит.

Плашка снизу по центру показывает, что делает Алиса, по звуку, без Яндекса:
- «Я вас слушаю» — микрофон Яндекса открыт дольше 0,4 с;
- «Думаю...» — микрофон закрылся, речи ещё нет;
- «Говорю» — играет речь, полоски по громкости захвата;
- «Маршрут в навигаторе» — 5 с.

Плашка появляется с джинглом, а не по нажатию (Егор). Микрофон, открытый до нажатия или дольше 10 с, — фоновое
прослушивание Яндекса, его не считаем. Если после ответа заиграла музыка, плашка уходит. Тап по плашке закрывает Алису.

## Альтернативы

- Алиса на экране телефона, ловить маршрут оттуда: на заблокированном телефоне не работает.
- Сами нажимать «Поехали» в шаблоне навигатора: работает (`car_click`), Егор отказался.
- Открывать голосовой поиск Яндекса (`MainActivity` + `EXTRA_REQUEST_VOICE_SEARCH`) на скрытом дисплее мимо сессии:
  BroAliceActivity не поднялась. Запуски Яндекса из shell и force-stop ломали его голосовую сессию до перезагрузки.

## Последствия

Нужна Алиса помощником по умолчанию (проверено только так) и автозапуск Яндекса на MIUI. Перенос задач посреди
перехода MIUI однажды оставил на телефоне призрак окна, глотавший жесты. Первые 4 с ловец тянет на скрытый дисплей и
окно Яндекса, открытое на телефоне руками. Иконка Алисы лежит в ресурсах (`alice_icon`). В машине не проверено.
