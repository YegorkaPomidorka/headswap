# 0006. Обходы под ГУ включаются флагом по каналу/модели, а не глобально

- Статус: принято
- Дата: 2026-10-14 (PR #18, #10), до 2026-10-30 (PR #113)
- Источники: PR #10, #18, #56, #72, #89, #113, кейсы h93, `aa/AaBridge.kt:192-214`, `:412-424`, `:642-710`

## Контекст

В 1.1.6 был глобальный keepalive на PAUSE. Правка под Mazda и VW ломала Honda (h93). Разные ГУ рвут связь по разным
причинам, а опробовать обход можно только на живой машине.

## Решение

Каждый обход — отдельный флаг в `AaBridge`: `huDesayG6S`, `huVw20082120`, `huVwBt1420`, `huVwCns2Delphi`,
`huHyundaiCn7`, `huHonda20772121`, `huMazda20622111`, `huMobisNx4c` (`AaBridge.kt:192-214`). ГУ опознаётся по
`HU_INFO` (manufacturer/model/product) или `STATISTIC_INFO.channel` (`:642-710`). Флаги сбрасываются при каждой
новой сессии, пока ГУ не представится заново (`:412-424`). Обход действует только на своём ГУ, в тестовых сборках тоже.

## Альтернативы

- Глобальный keepalive (1.1.6) — ошибка, разнесён по ГУ в PR #18.
- Самообучаемый `PauseKeepalive` — отложен после 3.0.0. Форк github.com/mhzsajan/headswap (reliability-форк на базе
  2.5.0, сборки `2.5.0-reliability5`), файл `PauseKeepalive.kt`. Идея: канал, оборвавшийся на PAUSE через ≥ 3,5 с
  с пустым VIDEO_DATA, запоминается по паре «канал/транспорт», и дальше heartbeat шлётся сразу. Заменил бы ручные
  флаги h93, h222, h224, h425, h211. Исключения: «Стоп» пользователя, heartbeat уже слали, Desay G6S по USB.
  Отложен, чтобы не смешивать с прямым пробросом (SPS-кроп, свой IDR) в 3.0: иначе не понять, что сработало и что
  сломалось. Брать отдельной тестовой сборкой.

## Последствия

- Привязку для VW пришлось менять. Сначала обход включали по имени BT ГУ («VW BT 4370», «VW BT 9491»), но имя у каждой
  машины своё, и под каждого нового владельца приходилось дописывать строку. PR #113 перешёл на канал прошивки
  (20082138) с исключением «VW BT 1420», которой обход вредит, а там, где канал общий с другими машинами, — на пару
  «канал + имя» (`AaBridge.kt:682-690`, `VW_ID_IDR_LIMIT_HUS`).
- Все Honda по логам ведут себя одинаково — их фиксы на всю марку. VW и Mazda все разные — их фиксы по модели или каналу.
- Новый обход добавлять с логом при включении и сбросом на новой сессии; не менять поведение остальных ГУ.
