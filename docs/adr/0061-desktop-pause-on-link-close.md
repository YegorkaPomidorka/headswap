# 0061. Рабочий стол: пауза плеера сразу при обрыве сессии

- Статус: принято
- Дата: 2026-11-24
- Источники: h1407 (Skoda CNS3, Wi-Fi), h1408 (Hyundai CN7, USB), h1406; `DesktopMusicPlayback.linkClosed`,
  `DesktopMusicUsbLink.pauseOnClose`

## Контекст

В рабочем столе музыка идёт на ГУ через наш захват. Когда сессия обрывается, захват снимается и плеер играет в
динамик телефона. Vezel за ~1 с до выключения шлёт MUSIC=0, и плеер встаёт на паузу. Skoda CNS3 и CN7 этого не делают.
По USB пауза ставилась только по USB detach, через ~3 с после ошибки чтения (h1408). По Wi-Fi паузы не было вовсе, музыка
замолкала только с закрытием AA через 8 с (h1407).

## Решение

Паузу ставим при закрытии сессии, до снятия захвата. Условия: ссылка была готова (были кадры), захват звука шёл, это не
Стоп. Работает и по Wi-Fi (tcp6). Пауза та же, что при detach: одна выбранная локальная медиасессия, play при
реконнекте. По физическому USB при закрытии ставим паузу, только если трек можно потом продолжить. Иначе решает detach,
как раньше.

## Альтернативы

- Ждать USB detach, как было. Ошибка чтения у Samsung бывает с кабелем в гнезде, через 0,5 с идёт повтор. Но музыка и так
  уходит в динамик сразу после снятия захвата, так что ожидание её не спасало.

## Последствия

На коротком реконнекте (Samsung, Wi-Fi rearm) музыка кратко встаёт на паузу и продолжается сама. Пауза асинхронная,
хвост в динамике в доли секунды возможен. На машине и на стенде не проверено.
