# 0045. VW CNS3 20082122: звонок по флажку сообщаем ГУ, как на Delphi

- Статус: принято
- Дата: 2026-11-17
- Источники: h1239, h602, `AaBridgeCore.huReportsCalls`

## Контекст

На VW Tharu XR (CNS3, channel 20082122) с телефоном по BT собеседник не слышал водителя. Флажок «Сообщать ГУ о
звонках» был включён, но сообщение ГУ и пауза MEDIA работали только на VW CNS2 Delphi (h425). Фикс h602 на любую ГУ
в main не попал.

## Решение

Звонок сообщаем и на 20082122: флаг `huVwCns3_20082122`, общий признак `huReportsCalls` = Delphi или CNS3 20082122.
На прочих ГУ всё как было: обходы только под конкретную ГУ (ADR 0006). Тест h1239test1, юзер: «всё заработало».
