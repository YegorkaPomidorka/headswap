# 0032. Без строки статуса уведомления висят чёлкой

- Статус: принято (стенд)
- Дата: 2026-11-07
- Источники: `launcher/NotificationsUi.kt` (`NotificationsOverlay`, `NotchBody`), `launcher/LauncherRoot.kt` (`StatusBar`), `ui/DevScreen.kt`

## Контекст

На части VW ГУ сверху своя строка с часами и значками, наша её дублирует. Её хотят прятать, но к нижнему краю строки
привязаны язычок и шторка уведомлений, а золотая полоска лежит на самой строке.

## Решение

Тумблер «Скрыть строку статуса» в «Для разработчиков», по умолчанию выключен. Без строки от верхнего края экрана
висит чёлка цвета панелей с золотой полоской (пока есть непрочитанные). Язычок и шторка не выезжают сверху,
а вырастают из чёлки и сворачиваются в неё обратно (Егор: «как будто за неё тянут»). Полоска — отдельный слой,
прибитый по X над стыком плиток: внутри растущей панели она ездила вбок.

## Альтернативы

- Одна тонкая золотая линия по верху без плашки — нет: в машине в неё не попасть пальцем, похожа на артефакт картинки.
- Чёлка прячется, язычок выезжает отдельно (первый макет) — нет, Егору не понравилась анимация.

## Последствия

- Чёлка только там, где была бы строка (главный, настройки, вызовы); поверх окон приложений её нет.
- В узкой рейке время жило в строке — при скрытой строке часов нет, их показывает ГУ.
