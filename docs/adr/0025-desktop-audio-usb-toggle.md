# 0025. Звук рабочего стола снова по USB или Bluetooth на выбор, один переключатель на оба режима

- Статус: принято, заменяет 0020
- Дата: 2026-11-05
- Источники: жалобы после беты 7 (4.0), h658 (Desay G6SA RAV4 рвёт A2DP при старте CarLife), `dex/DexPrefs.kt`,
  `ui/SettingsScreen.kt` (`refreshUsbAudio`)

## Контекст

В бете 7 весь звук рабочего стола пустили по Bluetooth (ADR 0020). У многих ГУ Bluetooth-звук и CarLife вместе не
работают: звук уходит в динамик телефона.

## Решение

Возвращаем выбор. Строка «Звук через Headswap» снова активна и в режиме рабочего стола и управляет обоими режимами:
`DexPrefs.usbPlaybackAudio` читает и пишет тот же ключ `usbAudio`, что и режим AA. По умолчанию включено — звук по USB/Wi-Fi.

## Альтернативы

- Отдельный переключатель для рабочего стола — лишняя строка, а машина обычно одна и та же в обоих режимах.

## Последствия

- Захват звука даёт только активация с включённым переключателем. Кто активировал в бете 7, тому в настройках
  подсказываем повторить активацию; до неё звук по Bluetooth.
- Старый ключ `desktop_usb_playback_audio` больше не читается.
