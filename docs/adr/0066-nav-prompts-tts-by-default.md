# 0066. Подсказки навигатора по умолчанию снова в TTS

- Статус: принято, меняет дефолт из ADR 0060; режимы расширены в ADR 0071
- Дата: 2026-11-25
- Источники: h1455 (Hyundai ix35 HSAE 20022155), h1452 (Elantra CN7 20022179), h1450 (Vezel), `aa/NavChannel.kt`

## Контекст

В 4.3.4 подсказки по умолчанию шли в канал VR (ADR 0060). На других ГУ это ломает музыку: HSAE на VR_INIT шлёт
MODULE_CONTROL MUSIC=0, мост ставит плеер AA на паузу, и после подсказки музыка не возвращается (h1455). CN7 на каждый
звук навигатора рвёт MEDIA на 2–3 с (h1452).

## Решение

По умолчанию TTS, как до 4.3. VR остаётся в «Для разработчиков» → «Канал подсказок навигации» для ГУ, где нужна
отдельная громкость голоса (VW CNS3, h1318). Решение Егора 25.11.

## Последствия

Кто не трогал настройку, переходит на TTS со следующей подсказки. Юзерам CNS3 вроде h1318 VR надо включить вручную.
