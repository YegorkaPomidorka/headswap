# 0043. Стеклянная рейка, свёртка навигатора повторным нажатием, часы и дата в «Виде»

- Статус: принято
- Дата: 2026-11-17
- Источники: макет стеклянной рейки (Егор 17.11), `LauncherRoot.kt`, `LauncherSettings.kt`

## Контекст

Сплошная рейка с золотым блоком навигации тяжёлая. Повторное нажатие кнопки навигатора только перепроверяло
его задачу, свернуть его было нечем. «Вид» делился на крупные карточки с миниатюрами, а формат часов жил в «Экране».

## Решение

- Настройка «Стиль панели» (`rail_style`): «Сплошная» (по умолчанию) или «Стекло». Стекло только на боковой рейке
  в альбоме, в портрете игнорируется, строка настройки там скрыта.
- В стекле рейка - одна прозрачная колонка на всю высоту: белый градиент, светлая кромка у области, без свечения лого.
  Золотой блок заменён круглой линзой (диаметр кнопки рейки) по центру нижнего ряда плиток, над ней черта посередине
  зазора. Область справа - сплошной `bgSolid`. Без blur: фон под рейкой статичный.
- Повторное нажатие навигатора, когда он уже на весь экран, возвращает на главный, как лого на не-главном экране.
  Перепроверка задачи навигатора при смене экрана осталась (`LaunchedEffect(area)` в `EmbedUi`).
- «Вид» - список одинаковых рядов с сегментами справа; 12-часовой формат перенесён из «Экрана» в «Вид», рядом новая
  настройка формата даты (`date_mdy`): «ДД.ММ» по умолчанию или «ММ.ДД».

## Альтернативы

- Размытие фона под стеклом (RenderEffect): дорого для видеопотока на ГУ, а фон под рейкой всё равно статичный.
- Тень рейки на область: не делали, область справа сплошная и без неё читается.

## Последствия

Физическая кнопка NAVI на ГУ теперь тоже сворачивает открытый навигатор. Миниатюры «Боковой панели» убраны.
