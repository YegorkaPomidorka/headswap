# 0019. Полноэкранный YouTube в лаунчере прячет рейку; признак — requestedVisibleTypes задачи

- Статус: принято (на ГУ не проверено)
- Дата: 2026-11-04
- Источники: `launcher/LauncherLogic.kt` (`FullscreenApp`), `launcher/EmbedHost.kt` (`fullscreenTick`),
  `dex/DelegatedDesktopPolicy.kt` (`fullscreen`), `dex/FrameworkTaskIdentityPolicy.kt` (`requestedVisibleTypes`)

## Контекст

Егор: YouTube в полноэкранном режиме должен занимать весь экран, левая рейка прячется, выход — кнопкой самого YouTube.
Окно приложения — отдельный виртуальный дисплей, лаунчер видит только задачи через `getRunningTasks`.

## Решение

Полноэкранный режим = верхняя видимая задача дочернего экрана — YouTube, и её `TaskInfo.requestedVisibleTypes` без бита
`statusBars`. Поле скрытое (Android 15+): сначала рефлексия, потом последнее вхождение в `TaskInfo.toString()`,
как с displayId в `FrameworkTaskIdentityPolicy`. Новых прав, `dumpsys` и команд шелла нет.
Опрос раз в 0,5 с, только пока в окне YouTube. Рейка прячется после двух ответов «да» подряд;
1,5 с после смены размера окна «нет» не учитывается: YouTube перестраивается и может на миг показать панели.

Инвариант: при любом сомнении рейка видна — не YouTube, не тот экран, экран задачи не опознан, ошибка запроса,
окно не готово, ушли с экрана приложения.

## Альтернативы

- Любое приложение, прячущее панели, — нет: игры и плееры, скрывающие панели всегда, оставили бы без «Назад» и «Домой».
- `dumpsys window` («Requested non-default-visibility types») — нужно право DUMP в делегированный процесс, расширение прав.
- `isTopActivityImmersive` — это флаг `android:immersive` активности, не скрытые панели.

## Последствия

- Android 14 и ниже поле не отдаёт: ответ «неизвестно», рейка остаётся.
- В лог пишется `TASKS экран N: requestedVisibleTypes <пакет>:<значение>` при смене — по первому прогону видно, работает ли признак.
