# 0033. На Android 17 экран рабочего стола держит shell-хост VirtualDevice; требуется отладка по USB

- Статус: принято
- Дата: 2026-11-07
- Источники: логи h782 (Pixel), h827 (S25 Ultra), h768 (A55), h821 (S24+), SM-S942B; проверки на AVD A17;
  подход MoonClicker (MIT) и Shizuku; `dex/VdmHostMain`, `VdmDesktop`, `VdmHostRestart`

## Контекст

На Android 17 вшит флаг `separate_timeouts`: виртуальный дисплей рабочего стола попадает в группу 0 вместе с экраном
телефона, `OWN_DISPLAY_GROUP` игнорируется. Гаснет телефон — гаснет экран ГУ.

## Решение

Свою группу дают только дисплеи VirtualDevice (`DEVICE_DISPLAY_GROUP`). Создать VirtualDevice может только uid 2000
от имени `com.android.shell`. Поэтому лаунчер активации запускает `VdmHostMain` через app_process. Хост создаёт
CDM-привязку на shell, держит устройство и отдаёт binder приложению через `VdmHostProvider`. Нет хоста — экран
создаётся по-старому. Включено только с Android 17: с 16 жалоб нет (Егор).

Хост живёт в группе процессов adbd. На Samsung при каждом подключении и отключении ГУ кабелем меняется USB-режим,
adbd гасится, и хост гибнет вместе с ним без отчёта. Без отладки по USB adbd так и остаётся выключенным. С ней adbd
поднимается заново на новом порту, и приложение за ~2,5 с запускает хост снова через свою беспроводную отладку
(`VdmHostRestart`, порт ищет mDNS); экран ГУ ждёт хост до 12 с. Поэтому на 17 активация и главный экран требуют
«Отладку по USB», а перезапуск ограничен только неудачными попытками (SM-S942B: 5 удачных за 2 минуты при обрывах USB).

## Альтернативы

- Привязка CDM на наш пакет (vdm1): на 17 молча не создаётся.
- Вынести хост из группы adbd, как Shizuku: на 17 shell не может писать ни в один `cgroup.procs`, `/acct` нет.
- Перезапуск хоста без отладки по USB (vdm4–5): adbd не поднимается, старый порт отклоняет соединение, mDNS пуст.

## Последствия

- Дисплей принадлежит shell: приложению нужно право `START_ACTIVITIES_FROM_BACKGROUND`.
- Окна с `canDisplayOnRemoteDevices=false` на этот экран, вероятно, не пускаются (меню настроек у SM-S942B) — не проверено.
- Задачи виртуальных столов видны в недавних на телефоне.
- Требование «Отладки по USB» только на Samsung (h966, 08.11): на Pixel 7 Pro с включённой галочкой приложение
  читало «выключено», и активация не начиналась вовсе. Гибель adbd при смене USB-режима видели только на Samsung.
