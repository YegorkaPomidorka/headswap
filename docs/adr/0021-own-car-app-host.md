# 0021. Навигатор на рабочем столе — через свой хост Car App Library

- Статус: принято
- Дата: 2026-11-04
- Источники: стенд 04.11 (2ГИС, эмулятор ГУ 1280×720), хендофф `2026-11-04-car-app-host-feature`, пакет `carapp/`,
  `launcher/NavHostUi.kt`

## Контекст

Навигатор в окне рабочего стола — это телефонный интерфейс, мелкий и без подсказок манёвров для ГУ. Показывать
внутри рабочего стола экран Android Auto Егор отверг: «невизабельно иметь AA внутри». У 2ГИС (и других навигаторов
на Car App Library) есть машинная часть: CarAppService, которому хост отдаёт поверхность и получает шаблоны и маршрут.
2ГИС пускает любой хост (HostValidator allowAll).

## Решение

Headswap сам становится хостом Car App: находит навигаторы по CarAppService + категории NAVIGATION, карта рисуется
в нашу поверхность, шаблоны рисует лаунчер в стиле AA в золоте Headswap, Trip уходит на ГУ подсказками манёвра.
Хост и отрисовка не привязаны к вендору. Инварианты, найденные на стенде:

- **visible ≠ stable.** При равных областях 2ГИС прячет лимит скорости, камеры и мини-карту. Наши карточки слева,
  полоса кнопок справа и верхний ряд вычитаются из visible, stable ещё ниже на 15% высоты.
- **Одна полноэкранная поверхность.** Карточка на главном показывает вырезку (TextureView.setTransform).
  Пересдача той же Surface с новым размером вешает 2ГИС.
- **Состояние держит хост, как AA.** Выбор строки в списке и переключатели 2ГИС обратно не присылает.
- **APP_ICON в шапке — значок, не «Назад».** 2ГИС ставит его на стартовую страницу.
- **«Масштаб карты» — dpi, который отдаём навигатору.** Потолок — плотность окна (160 dpi на 1280×720),
  «Авто» = потолок / 1,5. Наши карточки масштабируются вместе с картой. Курсор 2ГИС держит один экранный
  размер при любом зуме, менять его можно только dpi.
- **Своих прав на локацию у Headswap нет.** Пользователь ставит 2ГИС «Разрешать всегда».

## Альтернативы

- Теневая AA в окне — отвергнута Егором.
- Навигатор обычным окном + исправление DPI Ильдара — остаётся для навигаторов, которые хост не пускают.

- День/ночь карты: машинная часть 2ГИС берёт её только у хоста. Фар в CarLife нет, CHANGE_MD_THEME ГУ не шлют.
  Сейчас UNDEFINED, то есть по теме телефона. Почему не иначе: ? (решение Егора открыто).
- Мини-карта 2ГИС после «шкала → мини-карта» пустая до повторного захода в настройки — баг 2ГИС, хост ни при чём.
  На мелких ступенях масштаба мини-карта уезжает к краю.
- Стрелку манёвра 2ГИС шлёт PNG 64×64 при любом dpi.
