# 0067. Обложка на приборке CR-V 6 (SEMIDRIVE X9): уникальный songId, повтор MEDIA_INFO, 16 КБ

- Статус: принято
- Дата: 2026-11-26
- Источники: PR #214 (автор — владелец CR-V 2026), `aa/AaMeta.MetaRelay`, `CarLifeSession.sendMediaInfo`, флаг `huSemidriveX9` (ch 21580005); тикеты h219, h606

## Решение

- `songId` = номер трека в сессии вместо постоянного "-1". Часть ГУ держит обложку в кэше по нему. Это поле протокола, а не обход, поэтому для всех ГУ.
- Обложку на приборке X9 меняет только повторный MEDIA_INFO. Повтор через 0,7 с подобрал автор на своей машине. Делаем его только для ch 21580005: остальным ГУ дубль ни к чему, а Mazda и Bon-Auto с мелкими пакетами лишний трафик не любят.
- Повтор уходит через нить `cl-meta` и только если новее MEDIA_INFO не было. В PR он шёл из `cl-sched` без проверки, и при быстром переключении копия старого трека ложилась поверх нового.
- Обложки крупнее ~16 КБ X9 не показывает: 25,8 КБ — иконка CarLife, 13–16 КБ — обложка. Для X9 лимит 16 КБ включается сам, у остальных — переключатель `metaArt16k`.

## Последствия

Другие ГУ SEMIDRIVE с той же проблемой надо добавлять по каналу.
