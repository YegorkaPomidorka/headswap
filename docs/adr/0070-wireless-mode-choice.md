# 0070. «По воздуху»: человек один раз выбирает способ из четырёх, бокс выбирается как Bluetooth-устройство

- Статус: принято
- Дата: 2026-11-28
- Источники: решение Егора 2026-11-28; `link/car/WlModePrefs.kt`, `link/car/WlScreenModel.kt`, `ui/SettingsScreen.kt` (`wirelessCard`), `BridgeService` (`ACTION_BOX`, `ACTION_BOX_AUTO`), `link/box/BoxConnector.kt`

## Контекст

В разделе «По воздуху» в одной карточке лежали три кнопки запуска (машина по Wi-Fi, свисток, бокс), выбор машины и поля сети машины. Человек не понимал, какая кнопка к его машине. Бокс стартовал только кнопкой, хотя Bluetooth и Wi-Fi к нему телефон поднимает сам.

## Решение

Егор, 2026-11-28: человек один раз выбирает способ из четырёх: Wi-Fi Direct, Wi-Fi машины, точка доступа на телефоне, бокс в USB. Дальше экран показывает только шаги этого способа.

- Бокс выбирается как Bluetooth-устройство, так же как машина в Wi-Fi Direct, и дальше подключается сам по ACL этого устройства. После выбора бокс стартует сразу.
- «Ждать свисток» из настроек убрано: вместо свистка бокс. Движок свистка (`ACTION_DONGLE`, `DongleListener`) остался в коде без входа из настроек.
- Что показывать, решает чистая `WlScreenLogic.screen` (режим, этап, выбрано ли устройство, BT рядом, точка включена); отрисовка читает только её результат.

## Альтернативы

- Узнавать бокс по имени «Dongle» без выбора — отклонено Егором: бокс выбирается явно, как машина. Подробнее причину он не объяснял.
- Отдельный тумблер «Подключаться самому» — не нужен: запомненное устройство и есть автоподключение.
- Сузить движок трёх машинных способов по выбранному режиму — не стали, нет машин для проверки. Режим ограничивает только использование сохранённой сети машины (`WlPolicy.useCarWifi`).

## Последствия

- Выбор хранится в prefs `wl_mode` (`WlModePrefs`, отдельный файл: `CarProfile.clear` его не стирает).
- Инвариант: устройство в `CarProfile` — бокс тогда и только тогда, когда `WlMode == BOX`. Переход через BOX забывает устройство (`WlPolicy.forgetOnSwitch`). Работающий сервис `set` не останавливает: перед сменой режима экран шлёт `ACTION_STOP`.
- ACL разводится по режиму: `ACTION_BOX_AUTO` против `WIFI_B_AUTO*`. Отбоя по ACL у бокса нет: он сам рвёт Bluetooth, как только поднялся Wi-Fi (проверено на телефоне 2026-11-28), и отбой гасил бы идущее подключение.
- Бокс в режиме BOX не одноразовый: перевзвод через 2 с после сессии, через 4 с после первых трёх неудач подряд и 10 с после следующих; после 8 неудач подряд перевзвод прекращается до следующего ACL_CONNECTED или ручного старта.
- «Стоп» глушит автостарт, пока ACL-события бокса идут чаще раза в 3 минуты (`boxMuted`, `boxSeenMs` в `WlModePrefs`); ручной старт снимает глушение.
- `CarLifeState.wlStage` (OFF/WAIT/LINK/UP/NO_LINK) — этап для экрана; пишет сервис.
- На машинах не проверено.
